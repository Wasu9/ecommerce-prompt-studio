How to use

1. Upload your product photo.
2. Select product-only or a model and upload a model reference if needed.
3. Choose 5/6/8/etc. images and the desired shots.
4. Generate prompts.
5. Tap Copy Prompt, paste it into ChatGPT image generation, create the image and download it.
6. Use the same saved model reference for future products when you want the same model.
